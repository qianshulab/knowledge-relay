# 知流同步插件

这个轻量插件只做一件事：把服务端已经整理好的微信消息、原附件和网页解析 Markdown，增量同步到当前 Obsidian 仓库的指定收件箱。

## 手动安装

1. 在知流后台“Obsidian 同步”页面下载插件 ZIP 并解压。
2. 把解压出的 `wechat-ilink-inbox-sync` 目录放到 Vault 的 `.obsidian/plugins/`。
3. 重启 Obsidian，在“第三方插件”中启用“知流同步”。
4. 在服务端打开“Obsidian 同步”，创建一个设备并复制令牌。
5. 在插件设置中填写服务器地址与令牌，点击“立即同步”。

## 收件箱模板

插件默认开启“优先使用收件箱模板”，默认路径是：

```text
90-系统/模板/T-快速捕获.md
```

模板存在时，插件会替换 `{{date}}` 和 `{{title}}`，并自动填充“一句话说明”“原始内容 / 链接”和同步附件。`来源` 优先记录消息里的第一个网址，否则标记为“微信 iLink”。它也支持以下可选占位符：

```text
{{date}} {{time}} {{datetime}} {{title}}
{{summary}} {{content}} {{source}}
{{message_id}} {{revision}} {{attachments}}
```

插件会额外在 frontmatter 保存 `知流消息ID` 和 `知流修订`，用于追踪来源。模板缺失或无法读取时会提示并安全回退到服务器生成的 Markdown，不影响同步 ACK。

同步批次只有在所有笔记和附件均写入成功后才会确认。每个附件都会校验 SHA-256；网页 Markdown 以 UTF-8 文本写入，其他附件按二进制写入。网络中断时，下一次会安全重试同一个批次并覆盖稳定路径，不会重复生成笔记。
